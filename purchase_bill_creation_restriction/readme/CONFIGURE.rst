No requiere configuración. Para que un usuario pueda crear facturas desde
Compras, darle en **Ajustes > Usuarios** un rol de **Contabilidad** que incluya
*Facturación* (por ejemplo, *Facturación* o *Administrador*).

Las facturas en borrador creadas antes de instalar el módulo no se borran:
las tiene que revisar un usuario de Contabilidad.
